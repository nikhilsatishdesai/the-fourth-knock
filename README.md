# The Fourth Knock

A short 2.5D murder mystery for desktop browsers, and the case study of how it was made.

- **Case study:** https://nikhilsatishdesai.github.io/the-fourth-knock/
- **Play:** https://nikhilsatishdesai.github.io/the-fourth-knock/play/ (desktop browser, keyboard, sound on, about 18 minutes, no install)

This repository is the published static site. `play/` is the frozen v1.0 web build, copied unchanged.

Creative direction, narrative, game direction and AI orchestration: Nikhil Desai. Built with AI systems under that direction; the case study's credits list each one.

Fonts: Newsreader, Barlow Condensed and Courier Prime, under the SIL Open Font License (licence texts in `fonts/`).
